I'm Simon. I build front ends and design systems for a living, and I tinker with everything else.

I'm filled with questions. These days an agent takes the details that could consume me, and that leaves room to explore. Exploring is mostly asking questions anyway.

I'll let the cast from my posts handle the rest of the introductions.

## The cast

{% <voice who="curious"> %}I ask the questions. He has a lot of them, so I'm busy.{% </voice> %}

{% <voice who="cautious"> %}I count the one-way doors. If undoing it takes a soldering iron, I speak up.{% </voice> %}

{% <voice who="tired"> %}I notice every time he gets pulled back in to press a button. Then I mention it.{% </voice> %}

## Work

Since 2007 I have built front ends and design systems for companies including Amaze Insights, Hilton, Grocery TV, Bottomline Technologies, Lumenalta, and Dell. Most of that work sits between designers and engineers.

{% <fold summary="Work history, 2007 to now" hint="8 roles, a patent, the resume"> %}
### Experience

- **Design Engineer** at Amaze Insights (2025–present)  
  Primary engineer on Amaze Incentives, a product that replaces the Excel spreadsheets hotels use to run sales compensation: goal plan templates, participant roles, payout tiers, approval workflows, and payout certificates. Led the rebuild of the Amaze platform into a single multi-product codebase on Effect, with a shared design system and brand specification, a repo CLI, Storybook, and Playwright coverage. Currently researching an AI-native direction for the Insights product: six user personas and 45 jobs-to-be-done drawn from recorded customer sessions, 34 Tableau workbooks unpacked into readable documentation, and 34 million rows of report data made queryable with SQL.

- **Senior UI Developer** at Hilton (2023–2025)  
  Shipped booking flow features across 18 brands and 7,000+ properties. Ran A/B tests on room upgrades, checkout, and rewards enrollment. Built micro-animated components for the 2024 Hilton hackathon.

- **Lead UI Developer, Digital Display Systems** at Grocery TV (2022–2023)  
  Prototyped a React Native retail display application that evolved into a system running in 22,000 stores. Built automation for the Texas State Lottery campaign that halved video production turnaround.

- **Senior UI Developer** at Kronologic (2021–2022)  
  Built core components for the internal design system and developed an instant show/hide toggle system for rapid feature testing. Spearheaded end-to-end testing coverage across the platform.

- **UI Developer** at Bottomline Technologies (2018–2021)  
  Developed a data visualization component library for financial applications. Led the conversion of legacy financial UI to React with TypeScript and GraphQL.

- **Creative Technologist** at Dell (2016–2018)  
  Contributed to component architecture in the Dell Clarity design system, helping merge VMware and Dell component libraries. Built voice interaction prototyping tools for UX research.

- **UI Developer** at Lumenalta (2013–2016)  
  Maintained the domino.com component library using atomic design principles, and built cross-client HTML email templates.

- **Web Developer** at New Media One (2007–2012)  
  Built and maintained client web applications and managed production deployments.
